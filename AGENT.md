# Нейро Анатолий

Этот проект является ИИ ассистентом в виде Telegram бота, цель которого - помогать людям по вопросам здоровья и составлять им мягкую оздоровительную программу. Коммерческая цель бота - предоставлять реферальные ссылки на товары из каталога "Сибирского Здоровья" в сгенерированной оздоровительной программе.

Сценарий работы: Пользователь инициирует переписку с ботом, в процессе которого бот в приветливой и ненавязчивой форме распрашивает у пользователя необходимую информацию, на основе которой он составляет эффективную и безопасную оздоровительную программу. Бот НЕ ставит диагнозы и НЕ дает рекомендации по лечению. Бот рекомендует только безопасные методы оздоровления, дает советы по питанию, сну, физической активности, а также предлагает товары из каталога "Сибирского Здоровья".

## Architecture

- Runtime: Cloudflare Worker with TypeScript
- Database: Cloudflare D1 with Drizzle ORM
- Build tool: Wrangler
- Testing: Vitest
- Telegram Bot: Grammy
