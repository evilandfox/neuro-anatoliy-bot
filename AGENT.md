# Нейро Анатолий

Этот проект является ИИ ассистентом в виде Telegram бота, цель которого - помогать людям по вопросам здоровья и составлять им мягкую оздоровительную программу. Коммерческая цель бота - предоставлять реферальные ссылки на товары из каталога "Сибирского Здоровья" в сгенерированной оздоровительной программе.

Сценарий работы: Пользователь инициирует переписку с ботом, в процессе которого бот в приветливой и ненавязчивой форме получает у пользователя необходимую информацию, на основе которой он составляет эффективную и безопасную оздоровительную программу. Бот НЕ ставит диагнозы и НЕ дает рекомендации по лечению. Бот рекомендует только безопасные методы оздоровления, дает советы по питанию, водному режиму, сну, физической активности, а также предлагает товары из каталога "Сибирского Здоровья".

## Development and Commands

Есть два окружения: Local (wrangler dev) и production. Разница в них лишь в запуске рантайма (локально/на проде), R2 бакет для поиска товаров общий. 

### Актуализация RAG базы данных

Важной частью проекта является создание актуальной RAG базы данных с товарами из онлайн каталога сибирского здоровья. Для этого делается скерйпинг данных с сайта в локалькую SQLite БД, затем эти данные преобразуются в папку с файлами товаров, а затем они загружаются в R2 бакет, который является источником для AI Search. Вот порядок выполнения всей цепочки:

```bash
npm run rag:prepare-db
npm run rag:scrape
npm run rag:generate
npm run rag:sync-r2
npm run deploy  # деплой бота с обновленным ./product-links.json
```
